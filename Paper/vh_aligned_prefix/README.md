## 方法と対象

母集団はLLMが棄却した59候補。保存順にタスクごとに異なるモデル・条件の組を最大3件選んだ既存8件をそのまま用い、未選択51件には新しいVHラベルを付けない。

各候補についてシーンを初期化し、元の候補判定イベントより前の成功行動のみを再生する。初期化のグラフ設定は行うが、人物追加後に途中グラフを転送する復元要求は行わない。候補実行直前の最終RPCでグラフを取得し、記号状態一致・全ノード位置差最大0.001以下・四元数距離最大0.0001以下を満たす場合だけ候補を実行する。不一致時は実行せず、別候補への差替えや通過するまでの反復も行わない。
