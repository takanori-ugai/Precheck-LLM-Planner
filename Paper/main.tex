\begin{summary}
% 「ショートノート」は 200 ワード，それ以外は200〜500 ワード
% 以内の英文でsummaryを記す
Household action planning requires identifying relevant objects and tracking their states and relations as actions are executed. This study examines a concrete implementation of sequential planning with large language models (LLMs) in VirtualHome. Code extracts object identifiers, states, support and containment relations, and agent relations from simulator graphs and converts them into text. An LLM generates an action, checks natural-language preconditions, and, when it rejects the candidate, identifies unmet conditions and regenerates the action once. The regenerated action is executed without another check. Verification and replanning are not claimed as new planning principles; the contribution is a documented implementation, a task collection, and diagnostic evidence about their limitations.

The collection contains 618 instances with templated instructions and varied initial conditions: 312 state-change and 103 placement test instances, with 203 instances reserved as prompt examples. The evaluation links overall task performance, component comparisons, and case analysis. The overall evaluation covers 18 conditions across the two task categories. GPT-4o with Multi Prompts and verification achieved 279/312 (89.4\%) successes for state changes and 84/103 (81.6\%) for placement. Success- and failure-specific action lengths characterize execution outcomes, while retrieval analysis examines the similarity between instructions and selected examples.

Component comparisons use four selected tasks, two models, ten conditions, and three repetitions, totaling 240 episodes with verified initial-state alignment. LLM verification versus no verification yielded 9/12 versus 8/12 successes for GPT-4o mini and 9/12 versus 9/12 for GPT-4o. Each count includes three successes on an initially completed task. Symbolic checks, post-failure repair, deliberation, and retrieval changes did not establish a uniform advantage. Process logs and case analyses distinguish precondition decisions, erroneous termination, and simulator execution failures. Of eight rejected-candidate replays, only two matched the corresponding decision state under symbolic and transform checks. Human ratings of decision responses did not assess the separately logged unmet-condition explanations. Differences in task coverage, execution settings, and available records limit comparisons across evaluation components. The findings provide diagnostic evidence, not general superiority, verified explanation quality, or real-world safety.

\end{summary}
